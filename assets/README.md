# Salzburg Verkehr logo

`salzburg-verkehr.svg` is the unmodified logo supplied by Salzburg Verkehr at:

https://fahrplan.salzburg-verkehr.at/webapp/customer/vs_svv/img/customer/svv-logo-mobile_new.svg

The PNG files in `custom_components/salzburg_verkehr/brand/` are transparent rasterizations of this SVG at 256 and 512 pixels. No colours or shapes were changed.
